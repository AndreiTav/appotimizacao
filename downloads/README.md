# Pacotes do NEXUS OPTIMIZER 0.1.0

- **NEXUS-OPTIMIZER-0.1.0-win-x64.zip**: aplicativo portátil com .NET incluído. Extraia tudo e abra `NEXUS OPTIMIZER.exe` no Windows 11 x64. Mantenha todas as DLLs e arquivos da pasta.
- **NEXUS-OPTIMIZER-0.1.0-win-x64.zip.sha256**: checksum SHA-256 do pacote portátil.
- **NEXUS-OPTIMIZER-0.1.0-source.zip**: código-fonte com projetos, lockfiles, testes, scripts e documentação.

Os pacotes foram compilados em Linux para Windows x64. A compilação Release terminou sem avisos e os 38 testes Core passaram. Os testes nativos, interface e UAC ainda precisam ser executados no Windows. Consulte o README principal e `docs/VALIDACAO-WINDOWS.md`; esta é uma entrega MVP, sem instalador ou assinatura digital.

No GitHub, abra o ZIP e use o botão **Download raw file** (ícone de download). Um repositório privado requer login de uma conta autorizada.
